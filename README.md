### About This Project

This IoT project provides efficient device intelligence services and helps engineers connect, deploy, integrate, operate, and manage IoT devices.

Engineers build and configure an architecture that connects an EdgeX Foundry server to IoT device gateways. Once configured, devices can be controlled through APIs or MQTT interfaces.<br>
These documents explain how to deploy and configure EdgeX Foundry and how to call the IoT device APIs and MQTT interfaces.

### Audience

These documents are intended for engineers who install, deploy, and develop IoT architectures. Readers should have:
- A basic understanding of IoT architectures and EdgeX Foundry.
- Familiarity with Linux and Docker containers.
- Basic networking knowledge.
