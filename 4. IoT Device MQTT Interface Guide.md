Register Android devices, control panels, business gateways, and other devices with EdgeX Foundry, then control them through the MQTT service interface.<br>
Before using these interfaces, subscribe your MQTT client to the `response_topic/#` topic.

## 1. General Interface
### 1.1 List Commands for All Registered Devices

**Request Topic**

```html
 request_topic/command_get
```

**Response Topic**

```html
response_topic/command_get
```

**Request**<br>
Request URL：
```html
http://edgex-core-command:48082/api/v1/device
```

Example Request Message：

```html
{
    "requestUUid":"000cfca0-50d9-4665-92e1-c7be3e4a2e0f",
```

### 2.2 Update Program Schedule

**Request Topic**

```html
request_topic/command_put
```

**Response Topic**

```html
response_topic/command_put
```

**Request**<br>
Request URL：
```html
http://edgex-core-command:48082/api/v1/device/{device_id}/command/{command_id}
```

Here, `{device_id}` and `{command_id}` correspond to the `edgexbody.id` and `commands.id` fields returned by EdgeX Foundry.<br>
The specific request URL is the value of the `url` field for the command whose `name` is `schedule`. For details, see [2.1 List Commands for the Android Music Box](#21-List Commands for the Android Music Box)。<br>

Request parameters:
| Name | Required | Type | Description |
| --- | --- | --- | --- |
| schedule | Yes | String | Update the Android music box program schedule<br>`mac`: Android music box MAC address |

Example Request Message：

```html
{
	"requestUUid":"ce123481-42f1-5ce5-12e0-234cgh5a1b1d",
	"methodUrl":"http://edgex-core-command:48082/api/v1/device/73e5aa47-9cdb-44fe-844c-3faf8598309e/command/c56cab3c-6ef8-4a55-a203-03c5f851e425",
	"methodParam":{
	"schedule":"{\"mac\":\"38CA73126BCB\"}"
	}
}
```

**Response**<br>
A successful response uses a 2xx status code, such as 200 or 204.<br>
For additional status codes and response parameters, see [5.1 Common Response Parameters](#51-Common Response Parameters) and [5.2 Status Codes](#52-Status Codes)。

### 2.6 Control Music

**Request Topic**

```html
request_topic/command_put
```

**Response Topic**

```html
response_topic/command_put
```

**Request**<br>
Request URL：
```html
http://edgex-core-command:48082/api/v1/device/{device_id}/command/{command_id}
```

The request URL is the `url` value for the command whose `name` is music_control . For details, see [2.1 List Commands for the Android Music Box](#21-List Commands for the Android Music Box)。<br>

Request parameters:
| Name | Required | Type | Description |
| --- | --- | --- | --- |
| music_control | Yes | String | Music control operation<br>`mac`: Android music box MAC address<br>action：Music command; allowed values:<br>- play：Play<br>- pre：Previous track<br>- next：Next track<br>- pause：Pause<br>- prelist：Previous playlist<br>- nextlist：Next playlist<br>- jump：Switch track<br>audio_id：Music file ID<br>When `action` is `jump`, set `audio_id` to the target music file ID; otherwise set it to `0`.<br>program_id：Playlist ID<br>When `action` is `jump`, set `program_id` to the target playlist ID; otherwise set it to `0`.<br> |

Example Request Message：

```html
{
    "requestUUid":"64ab903d-dc12-5803-70dc-d7210daf102b",
    "methodUrl":"http://edgex-core-command:48082/api/v1/device/73e5aa47-9cdb-44fe-844c-3faf8598309e/command/1f7a319a-d734-4966-a3d3-529472572e3d",
    "methodParam":{
     "music_control": "{\"mac\":\"38CA73126BCB\",\"action\":\"pause\",\"audio_id\":0,\"program_id\":0}"
    }
}
```

**Response**<br>
A successful response uses a 2xx status code, such as 200 or 204.<br>
For additional status codes and response parameters, see [5.1 Common Response Parameters](#51-Common Response Parameters) and [5.2 Status Codes](#52-Status Codes)。

###  5.3 Color Code Conversion
`colorX`: integer x value in the CIE XYZ color space.<br>
`colorY`: integer y value in the CIE XYZ color space.

Use the following formulas to convert `colorX` and `colorY` to RGB values:

```html
//X, Y and Z input refer to a D65/2° standard illuminant.
//sR, sG and sB (standard RGB) output range = 0 ÷ 255

x=colorX / 65536(`colorX` range: 0–65279)
y=colorY / 65536(`colorY` range: 0–65279)
Y = b*100/255.0 (`b` is the brightness value)
X = x * ( Y / y )
Z = ( 1 - x - y ) * ( Y / y )
var_X = X / 100
var_Y = Y / 100
var_Z = Z / 100
var_R = var_X * 3.2406 + var_Y * -1.5372 + var_Z * -0.4986
var_G = var_X * -0.9689 + var_Y * 1.8758 + var_Z * 0.0415
var_B = var_X * 0.0557 + var_Y * -0.2040 + var_Z * 1.0570
if ( var_R > 0.0031308 )
    var_R = 1.055 * ( var_R ^ ( 1 / 2.4 ) ) - 0.055
else
    var_R = 12.92 * var_R
if ( var_G > 0.0031308 )
    var_G = 1.055 * ( var_G ^ ( 1 / 2.4 ) ) - 0.055
else
    var_G = 12.92 * var_G
if ( var_B > 0.0031308 )
    var_B = 1.055 * ( var_B ^ ( 1 / 2.4 ) ) - 0.055
else
    var_B = 12.92 * var_B
sR = var_R * 255
sG = var_G * 255
sB = var_B * 255
```
